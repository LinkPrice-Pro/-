# 특별한 생일 · 솔향가득편백수 광고 운영 제안서

## 사용 방법
1. `index.html`을 열면 제안서가 표시됩니다. 설치나 빌드 없이 동작합니다.
2. GitHub 저장소의 `index.html`에 파일 전체 내용을 붙여넣거나 업로드합니다. 기존 파일을 유지하려면 `proposal.html` 등 새 이름을 사용합니다.
3. GitHub Pages가 설정된 저장소라면 업로드한 경로로 접속합니다. 이 전달물은 GitHub에 직접 업로드하지 않았습니다.
4. 상단 ‘목차’로 이동 메뉴를 열고 닫을 수 있습니다. ‘HTML 코드 복사’는 파일 전체를 복사합니다.
5. ‘발표 모드’에서 방향키·PageUp/PageDown·Home/End로 이동하고 Esc 또는 ‘발표 종료’로 돌아옵니다.
6. ‘PDF 저장’을 누르고 브라우저 인쇄 대상에서 ‘PDF로 저장’을 선택합니다. 전체 24페이지를 출력하도록 구성했습니다. 브라우저 머리글/바닥글을 끄고 배경 그래픽을 켜면 디자인을 보존할 수 있습니다. Chrome/Edge 권장. 강제로 A4를 선택하면 여백·배율이 달라질 수 있습니다.

## 포함 기능
- 24페이지 가로 슬라이드 / 페이지별 이동 목차 / 진행률
- 발표 모드와 이전·다음 이동 / 모바일 레이아웃
- 모든 슬라이드 PDF 인쇄 / 외부 라이브러리 없는 단일 HTML
- 페이백 14%와 12%의 차액·비용절감·추가매출 계산기
- 공식 자료 및 참고 자료 링크

## 데이터 기준
- 분석 기간: 2026-08-01~2026-10-25. 10월은 25일까지의 부분 기간입니다.
- 계정 원장: 파일명에 ‘파워링크’가 있는 4개 CSV. 실제로 파워링크·쇼핑검색·파워컨텐츠가 모두 포함됩니다.
- 파일명에 ‘쇼핑검색’이 있는 4개 CSV는 검색어 상세이며 원장에 더하지 않았습니다.
- 성과 판단: 구매완료 전환수·구매완료 전환매출. 총 전환매출과 구분합니다.
- 검색어 보고서는 검색 매체만 포함합니다. 원장에는 콘텐츠 광고비 799,588원이 추가되며, 검색 매체 합계도 1,251원 차이가 있어 원장 기준을 유지했습니다.
- 브랜드는 캠페인명·키워드 맥락에 따라 분류했습니다. 실제 상품 소속·연결 URL은 착수 시 확인합니다.
- VAT·기여기간·취소반품·순주문 중복은 미확인입니다. 매체 귀속 구매 전환매출이지 확정 순매출이 아닙니다.
- ‘구매 0건 비용’은 그룹×키워드/검색어의 기간 합산 기준입니다. 전체가 확정 낭비액은 아닙니다.
- 보고서의 지출은 모든 기존 상태(삭제 그룹 포함)의 역사적 실적을 포함합니다. 현재 활성 상태로 단정하지 않습니다.
- GFA 미진행/모수 없음은 광고주 전달 정보입니다. GFA 실적 데이터는 제공되지 않았습니다.
- 신규 키워드는 보고서에 나타나지 않은 후보입니다. 계정 내 미노출 등록 키워드와 중복할 수 있어 등록 전 조회합니다.
- 테스트 예산·증감률·연령·기간·분기 방향은 제안값입니다. 성과 예측 또는 보장 수치가 아닙니다.

## 근거 CSV
